# SS Traders Mattress

A lightweight, SEO-conscious Astro website starter for SS Traders Mattress.

## Setup

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Before launch

- Confirm that the domain `https://www.sstradersmattress.co.in` points to this deployment.
- Replace the sample product and bedroom photography with approved company/product photographs.
- Confirm which mattress sizes are available for each product before publishing product-specific availability.
- Add verified business hours and Google Business Profile details if available.
- Test the contact form after connecting a form endpoint. The current form uses `mailto:` as a simple fallback.
